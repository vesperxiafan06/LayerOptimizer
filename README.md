# 图层优化助手 - Figma插件

## 简介

图层优化助手是一款专为Figma设计师打造的插件，用于自动检测并优化设计稿中的无效嵌套结构和冗余图层。通过智能分析设计稿的层级结构，帮助设计师保持文件整洁、提高工作效率，同时确保优化过程不会改变设计元素的样式、尺寸、间距和位置。

## 核心功能

### 1. 扫描并标记设计稿中的无效嵌套

- 自动识别多余的嵌套结构
- 检测深层嵌套（超过3层）的情况
- 考虑自动布局、约束等特殊情况

### 2. 识别并高亮冗余图层

- 检测不包含任何视觉效果的容器
- 智能分析图层的实际作用
- 排除具有特殊属性（如自动布局、约束等）的图层

### 3. 一键优化功能

- 自动移除无效嵌套
- 清理冗余图层
- 保持设计元素的样式、尺寸和位置不变
- 实时显示优化进度和结果摘要

## 使用方法

### 安装插件

1. 在Figma中点击菜单 -> 插件 -> 浏览插件商店
2. 搜索"Layer Optimizer"
3. 点击运行

### 使用步骤

1. 在Figma中选择需要优化的图层或组件
2. 点击菜单 -> 插件 -> Layer Optimizer -> 打开插件
3. 在插件界面中点击"扫描"按钮，检测选中区域的问题
4. 查看检测结果，包括无效嵌套和冗余图层的详细信息
5. 点击"优化"按钮，自动修复检测到的问题
6. 查看优化结果摘要，了解具体修复的内容

## 注意事项

- 使用前建议先备份您的设计文件
- 插件会保持设计元素的样式、尺寸和位置不变
- 对于特殊用途的嵌套结构（如为了动画效果），插件可能会将其识别为问题，请根据实际需求决定是否优化
- 优化过程中如遇到错误，插件会显示详细的错误信息，帮助您了解具体情况
